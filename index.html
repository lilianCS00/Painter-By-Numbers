How It Works

1

Image Triplets

Each training sample contains three images: two from the same artist (positive pair) and one from a different artist (negative example)

2

Feature Extraction

ResNet18 extracts 256-dimensional embeddings from center-cropped 224x224 pixel images

3

Distance Learning

Triplet loss minimizes distance between same-artist pairs while maximizing distance between different artists

4

Classification

Model predicts if two paintings are by the same artist by comparing Euclidean distances in embedding space

Dataset Information

Data Split

  • Training: Multiple artists with image pairs
  • Validation: 20% of training artists
  • Testing: Separate set of artists

Data Augmentation

  • Random rotation (±15°)
  • Random horizontal/vertical flips
  • Random affine transformations
  • ImageNet normalization
